# Состояние реализации

Обновлено 30 октября 2026 года. Локальный этап готов, внешнее подключение выполняется.

## Готово и проверено

- React + TypeScript + Vite, мобильный интерфейс и значок для iPhone.
- Идея и план дня; бюджеты 2000–6000 ₽ с шагом 1000.
- Ручные погодные условия, категории, дата, время старта, транспортный резерв.
- Генератор учитывает еду, общую сумму, расписание и приблизительные перемещения. Замена сохраняет остальные пункты.
- Демонстрационные личные сохранения, обмен, ручная общая история, общий лайк, блокировки и экспорт.
- Подключаемый клиент Supabase, экран настоящего входа, административное создание двух аккаунтов.
- Схема PostgreSQL с RLS; атомарное обновление афиши, серверная функция импорта и шаблон ежедневного расписания.
- Проверка публичной конфигурации запрещает серверные секреты в клиентском приложении.
- GitHub Actions для проверок и публикации Pages по ручному запуску.

Проверки: **25 автоматических тестов прошли**, сборка TypeScript + Vite успешна. Тесты RLS выполнены в настоящем локальном PostgreSQL через PGlite с ролями A/B/посторонний/anon. Это ещё не тест размещённого Supabase Auth.

Отдельно выполнен `deno check supabase/functions/import-events/index.ts`: найдены и исправлены две ошибки типов серверного обработчика; повторная проверка прошла. Серверная проверка добавлена в workflows проверок и публикации.

Через браузер проверены: генерация дня, сохранение, скрытие от второй демороли, явный обмен, чтение общего плана второй ролью, ручная история и общий лайк, отдельная идея и её замена. Проверены выбор 4000/5000 ₽ и мобильный экран 390 px без горизонтального переполнения. Тестовые записи создавались на отдельном адресе/порту, а не в пользовательской вкладке.

## Прочие ограничения первой версии

- Время пути и часть расписаний приблизительные; пользователь проверяет их по ссылкам.
- Кафе используют плановый лимит на обед, а не проверенный средний чек.
- Граница географического фильтра — консервативный внутренний контур; пограничные места могут не попасть в выдачу.
- Экспорт есть, автоматического восстановления через интерфейс пока нет. Для резервной копии личных сохранений обоих пользователей нужен экспорт из каждого аккаунта.
