# Как сделать приложение доступным в интернете

Сейчас адрес `http://127.0.0.1:5173/` ведёт на приложение, запущенное на вашем Mac. На другом устройстве `127.0.0.1` означает уже само это устройство. Для доступа с телефонов нужен опубликованный сайт.

## Выбранный путь

1. **GitHub** хранит открытый код приложения. Аккаунт этого сервиса нужен владельцу проекта, а не каждому посетителю сайта.
2. **Supabase Free** хранит аккаунты приложения, личные сохранения, историю и оценки. Для владельца это отдельный аккаунт сервиса; пользователям достаточно входа в само приложение.
3. **GitHub Pages** размещает собранный интерфейс и выдаёт постоянную HTTPS-ссылку. После публикации Mac можно выключить: сайт и база будут работать на серверах сервисов.

Публикация подготовлена в `.github/workflows/pages.yml`. Она проверит серверный код, тесты и сборку, затем загрузит приложение. Для размещения сначала нужны созданные владельцем аккаунты сервисов и настроенный проект Supabase.

Пошаговая настройка находится в [SETUP.md](./SETUP.md).

## Кто сможет пользоваться

**Личный вариант для пары:** адрес сайта доступен из интернета, а сохранения и история открываются только после входа в один из ваших двух аккаунтов. Такая модель уже предусмотрена в коде.

**Приложение для других пар:** кроме публикации нужны самостоятельная регистрация, создание пространства пары, приглашение партнёра и настройки каждой пары. Сейчас регистрация закрыта; её нельзя считать готовой только потому, что опубликован сайт. Существующие RLS-политики уже отделяют данные разных пар, но полный сценарий самостоятельного подключения ещё не реализован.

Открытый код и адрес сайта не означают общий доступ к личным сохранениям. Эти данные остаются в базе с проверкой прав.

## Стоимость

Старт возможен на бесплатных тарифах и адресе GitHub Pages, без покупки домена. Бесплатный Supabase имеет лимиты и может приостановить проект после недели низкой активности; для публичного сервиса с постоянной доступностью это ограничение нужно учитывать.

Источники: [создание сайта GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site), [тарифы Supabase](https://supabase.com/pricing).
